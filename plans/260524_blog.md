# Blog

Add a personal blog to the website. Static, file-based, MDX-authored, design-consistent with the rest of the site.

## Goals

- Publish posts by committing MDX files. No CMS, no DB, no runtime fetch.
- Posts are part of the build output (static), deployed via the existing Cloudflare pipeline.
- Visual language matches the rest of the site (hand-styled, no generic prose theme).
- Drafts are visible locally for review, hidden in production.

## Stack

- **Content layer:** [Content Collections](https://www.content-collections.dev) — typed frontmatter (Zod), native Vite plugin with HMR, JSON output consumed by route loaders.
- **Authoring:** MDX (`.mdx`) — markdown plus optional JSX components.
- **Syntax highlighting:** Shiki via `rehype-pretty-code` (build-time, zero runtime JS). Theme: `github-dark-default`.
- **Monospace font:** Space Mono via `@fontsource/space-mono` (companion to existing Space Grotesk). Update `--font-mono` in `src/assets/global.css` to `'Space Mono', ui-monospace, monospace`.
- **Styling:** Tailwind v4 + custom MDX component map (no `@tailwindcss/typography`).
- **Routing:** React Router v7, file-based, consistent with existing routes.

## Content location

Posts live **outside** `src/`, at the repo root:

```
/content/blog/<slug>.mdx
```

Rationale: content is data, not source code; keeps `src/` for app code only.

## Frontmatter schema

Required:

- `title: string`
- `date: string` (ISO date, used for sort order on the index)
- `excerpt: string` (used in list preview + `<meta name="description">`)

Optional:

- `draft: boolean` — when `true`, post is included in dev builds only; excluded from production output.

Slug is derived from filename (`my-post.mdx` → `/blog/my-post`). No `slug` field.

## Content Collections config

- Collection name: `posts`.
- Input glob: `content/blog/**/*.mdx`.
- Output: typed JSON consumed via `import { allPosts } from 'content-collections'`.
- MDX via `@content-collections/mdx` with `rehype-pretty-code` (Shiki) for code blocks.
- In dev (`import.meta.env.DEV`): include drafts.
- In prod build: filter `draft === true` out at the collection transform so they never ship.

## Routes

- `/blog` → `src/routes/blog.tsx`
  - Loader returns posts sorted by `date` desc.
  - Renders a list: title, date, excerpt, link to detail.
- `/blog/:slug` → `src/routes/blog.$slug.tsx`
  - Loader finds post by slug; 404 if missing (or if `draft` in prod).
  - Renders MDX content with the custom component map.
  - Sets `<title>` and `<meta name="description">` from frontmatter.

## MDX component map

Custom-styled mapping for `h1`–`h4`, `p`, `a`, `ul`, `ol`, `li`, `blockquote`, `code` (inline), `pre` (block, Shiki-themed), `img`. Implemented once, applied via `MDXProvider` or a shared wrapper component. No external prose plugin.
