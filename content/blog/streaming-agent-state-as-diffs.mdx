---
title: Streaming agent state as diffs, not events
date: 2026-03-22
excerpt: SSE event soup is the wrong primitive for AI UIs. diffcp streams the state itself, as compressed JSON deltas.
---

Most production AI surfaces look the same: a message stream, a tool-call stream, maybe citations stapled on. It works, and it is also the ceiling. Adding a new affordance means a new event type, a new reducer case, and a regression risk on every existing screen. Teams that shipped the fourth event type in a week take two months on the eighth.

The reframe: an agent is not emitting events. It is mutating a structured state the client should observe.

## Stream the state, not the events

[`diffcp`](https://github.com/axelered/diffcp) is a small protocol built on that reframe. Define the shape your client cares about, mutate it on the server, ship the deltas. Four message types (`init`, `delta`, `done`, `event`), three diff ops (`s` set, `a` append, `d` delete), NDJSON on the wire. `append` is first-class, which is what makes token streaming a normal case rather than a special one.

The frontend reducer disappears, because there is nothing to reduce. The next state arrives already assembled.

## Server

```ts
import { ObjectStreamResponse } from '@diffcp/core'

type Message = { text: string; toolCalls: { name: string; args: unknown }[] }

async function* streamMessage(): AsyncIterable<Message> {
  yield { text: 'Looking', toolCalls: [] }
  yield { text: 'Looking that up', toolCalls: [] }
  yield { text: 'Looking that up', toolCalls: [{ name: 'search', args: { q: 'diffcp' } }] }
}

export function GET() {
  return new ObjectStreamResponse(streamMessage())
}
```

The generator yields snapshots. diffcp computes the delta. Nothing here knows about the wire.

## Client

```tsx
import { useObjectStream } from '@diffcp/react'

function Chat() {
  const { value, done } = useObjectStream<Message>({ url: '/api/chat' })
  return (
    <>
      <p>{value?.text}</p>
      {value?.toolCalls.map((t, i) => <ToolCall key={i} call={t} />)}
      {done && <Footer />}
    </>
  )
}
```

That is the API.

## What this changes for a team

Adding a field is a one-line type change and a one-line render. No protocol negotiation. No reducer to grow. Bugs collapse to one class, "the state is wrong", which a snapshot test catches in seconds.

The real win is what the team can ship next. Once a new field costs nothing, agent UIs can go past the message-plus-tool envelope: live-updating plans, structured outputs that render as they form, multi-pane workspaces backed by one evolving state, collaborative surfaces where the agent and the user converge in the same model. Products customers notice. Not feasible on a wire format that treats every new affordance as a protocol change.

## The protocol

NDJSON on the wire, a deliberate subset of JSON Patch for the diffs, framing borrowed from React Server Components streams. Standards where they fit, no invention for invention's sake. And for the cases where something really is an event and not a state change, there is an `event` message type for it.
